#  FASAD38.PRO — Лендинг для компании по производству фасадных термопанелей

Одностраничный сайт-визитка для компании, занимающейся производством и монтажом фасадных термопанелей в Иркутске и Ангарске. Сайт создан для презентации продукции, демонстрации преимуществ, расчета стоимости и привлечения клиентов.

##  Функционал

*   **Адаптивный дизайн:** Полная поддержка мобильных устройств, планшетов и десктопов.
*   **Фиксированная шапка:** При скролле шапка меняет прозрачность на плотный фон с тенью, цвета элементов меняются на брендовые.
*   **Бургер-меню:** Для мобильных устройств — выезжающее меню с блокировкой скролла страницы.
*   **Плавный скролл:** Плавная прокрутка к якорям навигации.
*   **Карусель примеров работ:** Собственный слайдер с поддержкой свайпов, точками навигации и адаптивным количеством карточек (1 на телефоне, 2 на планшете, 3 на ПК). Данные подгружаются асинхронно из `data.json`.
*   **Интерактивный калькулятор:** Расчет ориентировочной стоимости панелей в реальном времени по площади стен (ползунок + поле ввода).
*   **Анимации:** Плавные ховер-эффекты на карточках, кнопках и элементах.

##  Технологии

*   **Frontend:** HTML5, CSS3 (Flexbox, Grid, CSS-переменные), JavaScript (ES6+, Fetch API, DOM).
*   **Хостинг:** GitHub Pages (или другой).
*   **Особенности:** Адаптивная верстка с нуля, без использования сторонних фреймворков и библиотек.

##  Ключевые технические решения

### 1. Собственный слайдер (карусель)
Вместо подключения тяжелых библиотек (Swiper, Slick) был написан собственный легковесный слайдер:
*   Динамическое вычисление ширины карточек в зависимости от ширины контейнера.
*   Поддержка свайпов на тач-устройствах (`touchstart` / `touchend`).
*   Автоматическое создание точек-индикаторов.
*   Адаптивность: пересчет при изменении размера окна (`resize`).
*   Данные для карточек хранятся в `data.json` и загружаются через `fetch`.

### 2. Калькулятор стоимости
Логика калькулятора полностью вынесена в JS:
*   Стоимость рассчитывается исходя из цены за панель и площади одной панели.
*   Синхронизация ползунка (`range`) и поля ввода (`number`).
*   Валидация ввода (ограничение от 1 до 1000 м²).
*   Форматирование итоговой суммы с разделителями тысяч (`toLocaleString('ru-RU')`).

### 3. UX-решения
*   **Шапка:** Эффект «залипания» с изменением стиля при скролле — классический прием для лендингов.
*   **Мобильное меню:** При открытии бургера `overflow: hidden` на `body` запрещает прокрутку фона.
*   **Ссылки-якоря:** Плавный скролл через `scrollIntoView({ behavior: 'smooth' })`.
